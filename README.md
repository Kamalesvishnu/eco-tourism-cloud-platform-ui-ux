# eco-tourism-cloud-platform-ui-ux
Designed a complete UI/UX solution for the Eco Tourism Cloud Platform (ETCP), focusing on sustainable travel experiences. The project includes user research, personas, empathy maps, user flows, wireframes, high-fidelity UI designs, and a comprehensive design system created in Figma.
